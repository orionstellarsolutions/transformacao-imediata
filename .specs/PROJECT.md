# Projeto: Transformação Imediata - O Código da Mente

## 1. Visão do Projeto
Plataforma web imersiva de alta conversão para a mentoria **O Código da Mente** (Mente Livre), combinando uma experiência de abertura gamificada em WebGL (Cryptex 3D interativo) com uma landing page de vendas de alta performance.

## 2. Objetivos Principais
- Proporcionar uma experiência de entrada memorável e de alto valor percebido ("a chave está dentro de você").
- Taxa de conversão otimizada com copy persuasiva e navegação fluida.
- Conformidade estrita com o orçamento de performance mobile e arquitetura Cloudflare Pages/Workers da Orion Stellar Solutions.

## 3. Stack Tecnológica
- **Framework:** Vue 3 (Composition API `<script setup>`) + TypeScript + Vite.
- **Estilização:** Tailwind CSS (cores personalizadas gold e dark surface, tipografia Cinzel e Inter).
- **Computação Gráfica & Animações:** Three.js + Web Audio API (sintetizador nativo) + GSAP/CSS Transitions.
- **Qualidade & Testes:** Vitest + Vue Test Utils + ESLint + Vue-tsc (cobertura $\ge 95\%$).
- **Hospedagem & CDN:** Cloudflare Pages com compressão e cabeçalhos em `public/_headers`.
